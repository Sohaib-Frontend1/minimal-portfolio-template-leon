# Leon - Minimal Creative Agency Web Template

A pixel-perfect, fully responsive single-page web template for creative agencies and freelancers. The project was meticulously coded from a PSD design to ensure high fidelity, semantic structure, and optimal performance.

## Design to Code
This template was built by translating an original PSD design into clean, modern HTML and CSS. A visual comparison between the original design and the final coded result is available in the `preview` folder.

## Intentional UI & Responsive Adjustments
- Right-Aligned Menu Toggle: Unlike the original PSD, the close (X) button in the mobile menu is intentionally positioned on the right. This decision improves accessibility for left-to-right (LTR) reading directions and enhances UX for single-handed usage on large mobile devices (specifically tailored for widths like 427px and 440px).
- Fully Responsive: Adapts seamlessly across desktop, tablet, and mobile devices using CSS Grid, Flexbox, and fluid media queries.

## Features
- Off-Canvas Navigation Menu: A custom-built, full-screen mobile menu using CSS `:checked` pseudo-class without heavy JavaScript.
- Smooth Scrolling: Implemented via vanilla JavaScript, accounting for the header height automatically.
- CSS Custom Properties: Centralized color palette and spacing for easy theme customization.
- Zero Dependencies: No external frameworks or libraries; purely HTML5, CSS3, and ES6 JavaScript.

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6)

## Project Structure
- index.html: The main HTML document.
- styles/style.css: The stylesheet containing all layout and responsive rules.
- js/script.js: The script managing navigation behavior.
- images/: Directory for all SVG icons, images, and logos.
- preview/: PSD mockups and final code comparisons.
